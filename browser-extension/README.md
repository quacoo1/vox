# Read with Vox — browser extension

Adds **Read with Vox** to the right-click menu of Chrome and Edge. The extension hands the selected text to the Vox
desktop app running on your computer, and Vox reads it aloud with your ElevenLabs voice. The floating player
appears just like when you read from any other app.

## Install (Chrome)

1. Open the Vox app → **Settings → Integrations** and make sure the **Chrome & Edge bridge** is on. Note the port
   (default `47823`).
2. In Chrome, open `chrome://extensions`.
3. Switch on **Developer mode** (top-right).
4. Click **Load unpacked** and choose this `browser-extension` folder. The Vox app can open the folder for you
   from **Settings → Integrations**.
5. Optional: pin the extension (puzzle icon → pin) to keep the Vox button in the toolbar.

## Install (Microsoft Edge)

1. Open `edge://extensions`.
2. Switch on **Developer mode** (left sidebar, or bottom-left on narrow windows).
3. Click **Load unpacked** and choose this `browser-extension` folder.

Chrome may show a "Disable developer mode extensions" reminder at startup. That is normal for extensions loaded
this way: choose **Keep** (or just close it).

## Use it

| Do this | Vox reads |
|---|---|
| Select text → right-click → **Read with Vox** | the selection (line breaks kept) |
| Select text → press **Alt+Shift+R** | the selection |
| Right-click an empty part of a page → **Read page with Vox** | the main article of the page (menus, sidebars and footers skipped, up to 20,000 characters) |
| Click the toolbar button | status, Read selection / Read page, Pause/Resume and Stop |

Change the shortcut at `chrome://extensions/shortcuts` or `edge://extensions/shortcuts`. The popup's **Change** link
opens that page.

If the toolbar icon shows a red **!**, the last read failed. Open the popup to see why. The most common reason is
that the Vox app is not running or is set to a different port.

## How it works

- The extension calls the Vox app's local bridge at `http://127.0.0.1:<port>`:
  - `GET /health` checks the connection (the white or red dot in the popup),
  - `POST /read` sends `{ text, url, title }`,
  - `POST /command` sends `{ "type": "toggle" }` or `{ "type": "stop" }`.
- Every request that changes something carries the header `x-vox-client: browser-extension`. The Vox app only
  listens on `127.0.0.1` and refuses requests from web pages: requests with a web `Origin`, CORS preflights and
  wrong `Host` headers all get `403`. Websites cannot make Vox talk.
- To read a selection, the extension runs a one-line script in the current tab (`activeTab` + `scripting`) to get
  the selected text with its line breaks. Where the browser forbids scripts (the built-in PDF viewer, the
  Web Store, `chrome://` pages) it uses the browser's own copy of the selection instead.
- The port is stored in `chrome.storage.sync`. The last error is stored in `chrome.storage.local` so the popup can
  show it.

## Privacy

- Text goes **only** to the Vox app on this computer (`127.0.0.1`). The extension makes no other network requests,
  has no analytics and reads nothing until you ask it to.
- The Vox app then sends the text to ElevenLabs to make the speech, using your own API key, as it does for any read.
  Vox keeps a local history of reads, which you can turn off in Vox **Settings**.
- Permissions:
  - `contextMenus` adds the right-click entries.
  - `activeTab` and `scripting` read the selection or the page, and only in the tab you clicked, only when you
    click.
  - `storage` stores the port and the last error.
  - Host access to `127.0.0.1` and `localhost` lets the extension reach the Vox app.

## Files

| File | Purpose |
|---|---|
| `manifest.json` | Manifest V3 definition |
| `background.js` | Service worker: menus, shortcut, page and selection extraction, error badge |
| `bridge.js` | Small client for the Vox local bridge, shared by the worker and the popup |
| `popup.html`, `popup.css`, `popup.js` | Toolbar popup |
| `fonts/` | Doto and Space Grotesk (SIL Open Font License, see the `OFL-*.txt` files) |
| `icons/` | Toolbar icons, generated by the app build (`npm run icons`) |
